03 · 작동 방식

Unlimited는 이렇게 작동합니다

핵심

무제한 생성

지원 모델에서 크레딧 차감 없이 생성

합리적 사용 정책과 일일 사용량 기준 적용

우선 처리

Fast 모드

우선 처리, Tier별 월 900~5,000회

미사용 횟수는 이월되지 않음

계속 사용

Standard 모드

Fast 소진 후 자동 전환, 계속 무제한

크레딧 차감 없음, 속도는 느릴 수 있음

동시 작업

병렬 생성

Tier별로 여러 개를 동시에 생성

상위 Tier일수록 팀 대량 작업에 유리

더 빠른 속도가 필요하면 Unlimited를 끄고 보유 크레딧으로 생성할 수 있습니다.

Artlist AI 온보딩 트레이닝 · 11

흐름 설명: Fast 횟수를 먼저 쓰고, 다 쓰면 Standard로 자동 전환되어 계속 무제한. Standard는 플랫폼 수요·모델 가용성에 따라 느려질 수 있음. 마감이 급한 컷은 Unlimited를 끄고 크레딧으로 빠르게 생성하는 것이 요령.
